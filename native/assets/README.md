# Launcher brand artwork

`curator-headshot.webp` is the unchanged 512×512 brand image used in the
navigation and footer of https://deck.dionlabs.ai/.

Source: `deck.dionlabs.ai/public/crew/curator-headshot.webp`, website commit
`8b11925` (confirmed against the deployed website on 2026-09-05).
The launcher installer converts this asset into the required macOS icon sizes.
